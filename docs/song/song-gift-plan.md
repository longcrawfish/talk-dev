song gift 网站规划
主题：数字音乐（礼物）定制
# 技术架构
前端：nextjs
数据库：cloudflare D1
文件存储：cloudflare R2
网站部署：cloudflare workers
账户登录：google account 授权登录
支付： creem
AI API（音乐生成、歌词生成、图片生成）： replicate / openrouter

## tools 业务流程
song gift 站的三款工具，操作体验要参照 digiflower.net 的工具组件「Bouquet Builder」，每个步骤切换都在当前网页内完成，步骤变化了当前网页不跳转，一步一步地引导用户完成创建。

song gift 站的三款工具，要做成可以复用的独立模块，方便在不同的工具页引入使用。

### 1. free-gift-maker
免费使用，不用登录；

操作步骤：
```
选场景（必选） -- 选择固定的音乐 -- 填写卡片（接收者名字，信息，发送者名字） -- 生成链接以及二维码
```
其中选择音乐和填写卡片步骤，用户至少操作一个。

音乐素材：采集一些可商用的音乐文件（来源：pixabay），文件存放于 cloudflare R2，以供网站调用；
把这些基础音乐文件做一个场景关联、配置，每个场景配置 2～3 首音乐，供用户挑选。

### 2. AI-song-maker
使用AI 大模型来创作音乐、歌词以及音乐封面图。

操作步骤：
```
选场景（必选） -- 选择音乐风格 -- 填写故事/想法（接收者名字，故事等）-- 生成歌词、预览（可以编辑歌词、可以重新生成歌词）-- 生成音乐（生成两个版本）-- 预览音乐，两个版本选一个 -- 选择封面（用户上传图片、选择 AI 生成，或者使用默认封面图片）-- 填写贺卡（可选）-- 生成分享链接
```

在「填写故事/想法」完成后，要进入下一步时，检查用户是否登录，如果已经登录那么进入下一步；如果没有登录，就弹窗提醒用户登录，登录完成后返回现场，继续操作；

在进行生成歌词前，要检查该用户的「创作草稿」记录，如果在24小时内超过9条创作草稿记录，那么要提示用户去「个人中心> 创作草稿模块」继续操作（删除部分草稿或者完成之前的操作），并给出站内跳转链接；

歌词生成之后，该创作可以记录一条创作草稿，在「个人中心> 创作草稿模块」能查看；接下来的每一步操作都在该草稿中记录；至到创作完毕，生成了分享链接，移除该创作草稿。

生成音乐这一步需要等待的时间较长，可以提醒用户等待 3～5 分钟，提示用户音乐生成完毕之后可以在「个人中心> 创作草稿模块」（站内链接）预览生成的音乐；
生成音乐（后台调用API、等待接口反馈，接口反馈后，存储文件）时，界面可以生成一个悬浮窗，让用户能看到系统在运作；等待的时间里，用户可以进入下一步操作 —— 选择封面、填写贺卡 —— 待音乐生成完毕，再进入预览步骤；

AI 生成的音乐、图片文件存放于 cloudflare R2；

预览音乐，用户可以听 50s 的音乐预览（假设生成的完整音乐时长不低于 2 min），用户在两个预览版本中选一个，解锁，扣积分，生成分享链接；如果积分不够那么进入 价格页/套餐页，选择套餐，支付购买积分，支付完毕再返回现场页面，继续操作。
如果两个预览版本的音乐，用户都不满意，可以选择重新生成音乐——弹窗，让用户修改之前的编辑内容——修改完毕，重新生成。

创作完毕，生成了分享链接，移除该创作草稿，同时将该礼品保存一条完成记录，在「个人中心> 创作完成的作品记录」可以查看、分享、下载音乐文件。

### 3. mixed-gift-maker
它是上述两个工具的混合版，操作步骤如下：
```
1. 选场景（必选） --  2. 选择音乐
``` 
在第2步「选择音乐」环节，提供 固定音乐 和 “personalized song gift” 音乐个性化定制选择项，
在第2步，如果用户选择了固定音乐，那么进入「free-gift-maker」接下来的步骤，免费、免登录：
```
3. 填写卡片 -- 4. 生成链接以及二维码
```

如果在第2步，用户选择了 “personalized song gift” 音乐定制选项，那么那么进入「AI-song-maker」接下来的步骤（在特定的步骤需要登录、支付积分）：
```
3.选择音乐风格 -- 4.填写故事/想法-- 5.生成歌词、预览-- 6.生成音乐-- …… -- 生成分享链接
```

## 用户个人中心
用户个人中心，必须登录之后才能查看，并且只能查看自己帐号相关的数据。

着重讲讲「创作草稿模块」，只有走AI 创作流程的草稿才被记录、保存，「free-gift-maker」的草稿服务端不保存；
每一个创作草稿，可以继续编辑、继续支付积分操作；
每一个创作草稿 继续编辑操作的工具体验要和「AI-song-maker」一致，可以复用该组件。

「创作草稿模块」，只保存用户在24小时之内的创作草稿，上限为10条，这需要在该页面给出提示信息。超过24小时的草稿，前端不再展示，后台要删除该资源（以及关联文件）；达到或超过10条的上限，要提醒用户完成创作或删除部分记录。

# 经济模型
网站除了免费的功能外，所有消耗都以积分的形式结算，主要是AI 工具的使用需要消耗积分。

积分管理
新用户，随机赠送一定数量的积分；
用户每日登录，随机赠送一定数量的积分；
用户付费购买积分。

积分有效期管理：
赠送的积分（新用户赠送、每日登录赠送）有效期为 30天；
付费购买的积分有效期为 180天；

# 推广营销
主要方式：
1. 工具站引流
2. 用户传播
3. 外链建设

## 1. 工具站引流
本人的其它工具站，在主题相关的页面加上 song gift 站的链接，为其导流，推进冷启动。

## 2. 用户传播
开发的免费工具「free-gift-maker」，免登录，让用户没有负担地使用；

AI 工具需要消耗积分，
考虑前期为新用户赠送多一点的积分、每日登录多送一些积分，给用户多一点的免费额度，让用户用的爽，多多使用、多多传播，
比如前1千名新用户，每个赠送 3n 数量的积分；第二个1千名新用户，每个赠送 2n 数量的积分；第三个1千名新用户，每个赠送 n 数量的积分；接下来的新用户赠送的数量逐渐减少。
网站上线后/或者设定一个日期，第一个90天，所有每日登录赠送 3m 数量的积分；第二个90天，所有每日登录赠送 2m 数量的积分；第三个90天，所有每日登录赠送 m 数量的积分；接下来的赠送数量逐渐减少。
（n、m 的数值待定）

前期给用户多一点免费体验积分，就是做推广了。

## 3. 外链建设
免费外链：ProductHunt、IndieHackers 等等
付费外链：theresanaiforthat.com，toolify.ai，creati.ai 等等 AI 目录站
