# 分享一个找需求词的方法

producthunt有一个免费 api 接口，可以根据日期拿到产品list， https://api.producthunt.com/v2/docs  ，
可以每天请求一次,拿到前一天发布的产品，解析产品的真实网站。

拿到网站后，就可以查 AITDK数据，拿到域名注册日期,流量，流量结构，核心搜索关键词等等数据。
https://aitdk.com/
https://tabapi.com/

我的筛选条件是：
1、域名注册时间在一年以内（代表新站）
2、月访问量超过3,000（拿到流量）
3、搜索流量和直接访问占比都超过20％（拿到搜索量且有二次访问证明网站是能解决用户需求的）

> 当然这里也可以根据 你们自己的筛选标准去改，你都拿到的 aitdk数据，想怎么整都可以。

筛选出网站后，我会继续查看它的搜索关键词，排除品牌词,只看需求词，就是用户寻找解决方案时使用的词

那么整个筛选思路就是：如果一个新站能够拿到非品牌词的流量，相当于这个关键词赛道，不是老站霸占，是对新站友好，现在还有机会的赛道！

接下来只需要判断自己是否对这个方向感兴趣、serp的站点你有没有机会做的比他们好,有把握直接就可以开干。

最后 ，重点是收集榜单，查aitdk，筛选非品牌词整套流程可以放在Cloudflare Worker上自动运行，做个cron,每天早上，系统会把符合条件的网站整理出来，具体操作可以ai一下。

另外，从目前我的数据看,大约每300个Product Hunt 产品，才能筛出一个符合我要求的网站，
目前我只做了 PH 一个站，如果添加更多导航站和榜单，那么就能找到更多需求词。
方法能节省大量前期筛选成本。
