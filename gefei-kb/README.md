# 哥飞建站知识库

整理「哥飞」关于做网站的知识与技巧，按主题分类，便于对照学习。

## 使用方法

1. 把原始素材（公众号文章、星球帖子、推文截图/文本、笔记等）放入 `inbox/`
2. 由 AI 整理归档到对应主题目录
3. 每篇文章整理为独立 md 文件，文件名格式：`YYYY-MM-DD-标题.md`

## 目录结构

| 目录 | 主题 |
|---|---|
| `inbox/` | 待整理的原始素材 |
| `01-关键词挖掘/` | 找词、选词、关键词工具、需求挖掘 |
| `02-SEO优化/` | 谷歌SEO、TDK、内链外链、收录、排名 |
| `03-建站技术/` | 程序选型、模板、速度优化、站点搭建 |
| `04-流量增长/` | 社媒引流、改版迭代、用户增长 |
| `05-变现盈利/` | Adsense、 affiliate、付费、商业化 |
| `06-心态与方法论/` | 做站心态、坚持、复盘方法 |
| `_meta/` | 索引、清单、模板等元信息 |
