# 从出站域名发现新需求新产品

> **一句话方法**：高流量内容站（如 vc.ru）会给大量新站带量 → 用 Semrush 查它的**出站域名** → 批量过滤 whois 注册时间 / Similarweb 流量 / Archive.org 收录 → 找出**新上线、正在推广、有流量**的产品，即当前被验证的需求。

## 核心流程

1. 选一个能给别的站带量的高流量网站（文中例子：`pikabu.ru`、`vc.ru`）
2. Semrush 查该站的出站域名（Backlinks → Outgoing/出站）
3. 批量收集域名，逐个查询：
   - **whois** → 域名注册时间（判断新旧）
   - **Similarweb** → 流量数据（判断是否真有量）
   - **Archive.org** → 历史收录（判断迭代轨迹）
   - （可选）谷歌搜索 API → 补充相关信息
4. 按条件筛选排序：如「近 N 月注册 + 谷歌已收录 + Archive 有记录 + 流量 > X」，按流量/注册时间排序
5. 结果 = 新上线且正在推广且有流量的新产品清单 → 需求/竞品情报

## 原理

新网站要推广就一定会到处留链接；这些链接指向的域名会出现在高流量站的出站域名里。所以**出站域名 = 新产品的曝光面**。
